# adolescentavos

Adolescentavos – Teens Point Management System
A full-stack project designed to gamify and manage the participation of church teenagers through a point system.
Built with Java 17, Spring Boot, Maven, and MySQL, following RESTful standards and clean architecture practices.

This project highlights:

Backend development with Spring Boot (JPA, DTOs, repositories, services, controllers).

Database design and integration with MySQL.

Use of best practices like DTO mapping, layered architecture, and clean code principles.

Currently under active development on the develop branch.
